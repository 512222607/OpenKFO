# 准备与战斗协议（BattleProtocol）

> 实现基线：`b74129b`，整理日期：2026-09-18。以当前 Go 实现为准，客户端笔记用于交叉参考；本轮未重新反编译或进行实机验证。偏移默认十进制，详见[总索引与约定](protocol.md)。

## 1. 准备、装载和进入战斗

| C消息 | S校验 | S应答与状态变化 |
| --- | --- | --- |
| 4030，0B | 已入房、room阶段、P2P有效；房主非训练房需≥2人，模式1/3需至少两队，其他成员已准备 | 本人Ready=true，广播4050(8B UID)；房主且全员Ready/P2P有效时分配serial、进入loading、向每人发送4080 |
| 4060，0B | 已入房且room、P2P有效 | Ready=false，广播4070(8B UID) |
| 4160，0B | 已入房且loading；已Loaded时静默幂等 | 标记Loaded，广播4170(8B UID)；全员后进入wait_ready并广播4180(0B) |
| 8040，14B | +0 u16房号、+2 u64本人UID；尾部4B当前未解释/未校验；需wait_ready | 标记Input；全员后进入battle并广播8070(12B) |

4080当前53B布局：

| 偏移 | 类型 | 当前写入 |
| --- | --- | --- |
| 0 | u32 | room.ID |
| 4 | u8 | 0 |
| 5 | u32 | room.Serial |
| 9 | u16 | 0 |
| 11 | u16 | 当前接收者Slot |
| 13起 | 8×u32 | 按peer.Slot索引填peer.P2P，其余0 |
| 45 / 49 | u32 / u32 | room.ID / room.Serial |

8070为 `[u32 room.ID][u32 room.ID][u32 room.Serial]`。资料对4080+11解释为房主/焦点槽，而代码填每个接收者自身Slot；这是后续开战专项待核对点。资料还记4120装配链，当前Go未发送4120，不能将当前屏障实现视为完整官方装配流程。

## 2. 战斗8071中继

外层opcode=8071，payload+0 u32为内层ID。仅battle阶段处理，校验发起UID、长度、相关房号/serial、有限浮点和玩家归属；按内层ID与序列去重后只转给同房其他人，不回给发送者。未知内层ID记限频日志后忽略。

| 内层ID | 当前总包体长度 | context偏移（房号/serial） |
| --- | --- | --- |
| 8120 | 108B | 无尾部context校验 |
| 8121 | 94B | 86/90 |
| 8122 | 51B | 无；+47 u32仅允许0..7 |
| 8126 | 71B | 无；目标位于+55 |
| 8140 | 103B | 95/99 |
| 8150 | 87B | 79/83 |
| 8440 | 71B | 无 |
| 8441 / 8451 | 47B | 无 |
| 8450 | 59B | 51/55 |

共同+4为发送者UID、+19为序列。8121/8126/8150额外检查来源与目标归属；训练模式中本地NPC不属于认证成员时忽略相关事件。当前是受校验的客户端事件中继，不是服务端权威物理/伤害结算。

消耗品使用与库存数量回执见 [ItemProtocol.md](ItemProtocol.md)，底层 UDP 中继见 [TransportProtocol.md](TransportProtocol.md)。资料中 4120 装配、4110 战报链当前尚未实现，不能把现有屏障和事件中继等同于完整结算。
