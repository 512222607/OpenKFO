## 多记录目录接入

当前PE A2BA90按26字节处理7080端点；A2BAD0检查7070是46字节倍数并交给910040。证据见native-catalog-arrays.asm。已在bootstrap与1157刷新中使用同一目录编码，每频道一个独立ID/路由，使用同一玩家回环桥接端口；不修改SDK认证网关目录。

配置示例（合并到现有服务器配置，不是完整配置文件）：

```json
{
  "lobby_ids": [1, 2],
  "lobby_names": {"1": "普通频道", "2": "新手频道"}
}
```

最多30个频道；ID非零且唯一，名称必须能完整GBK编码、1–20字节、无控制字符与首尾空白；不能给未列出的ID设置名称。未配置时原单频道报文逐字节保持一致。启动服务时校验配置，目录刷新也校验。名称是显示标签，目前不根据“新手”名称推导等级准入限制。

测试器增加可保存的频道ID输入，将其写入2010+8。TestCharacterCreationTLS在独立库/临时TLS服务验证两账号不同频道列表隔离，第二账号同隧道2060→2070→2010(频道1)→2030→1156，再验证同频道列表和退出移除；继续执行创建、重登、主动到期和删除回归。实际运行通过（33.425s），临时账号清理、临时数据库隧道关闭。
