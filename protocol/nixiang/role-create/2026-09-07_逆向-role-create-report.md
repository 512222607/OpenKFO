## 动态结果与边界

1. `1150/68 -> 1152/2` 只显示“操作成功”，不创建状态。
2. 新的 `1150/68 -> 1151/836` 使客户端安装模型并发出 `20432/8,20436/8,20440/8,3320/4`，界面仍在创建窗口。

4. 点击频道时曾发送角色 ID 为 1001 的 `3320`，但界面提示“祝您玩得开心”；再次点击没有新的非零消息。不能将其归因为服务端登录成功或认定已进入世界。

第一条 `3320` 的载荷是 `ed070404`，来源是 0x5499B0 读取对象 +340；该字段语义未恢复，不能强制将它解释成角色 ID。之后真实点击产生的 `3320` 则为 `e9030000`。新版服务按每条连接上的创建状态区分这两个场景。
