# 库存删除与过期的当前客户端证据

当前PE哈希和原始指令见native-inventory-delete-expiry.asm。本次只读文件反汇编，没有修改客户端。

- 注册2162：AF1AA5 -> A2C2C0。载荷必须恰好4字节，即一个uint32物品实例ID，无数量前缀。9CE160按实例ID从库存容器删除，随后刷新仓库界面。
- 注册2120：B230AA -> 8263A0。载荷为uint32数量以及连续uint32实例ID，逐一9CD7C0(instance,2)。另有81EBB0界面分支，尚未完整追踪。
- 注册2121：B231A2 -> 8266E0。同样逐一标记状态2，随后查道具配置生成过期提示。旧资料包号不同并不表示只能保留一个；当前客户端同时登记2120和2121。

服务器已将syncInventory中已消失实例改为2162增量删除，不再用1120全量替代；按ID排序，重复同步不再发包。没有新增客户端可任意删除实例的入口。仅处理已经持久化的库存差异。

验证：库存混合新增/更新/删除、删除全部、重复同步、其他会话不受影响的单元测试通过；独立测试库TLS用新临时账号验证删除后2430触发2162，重复查询不重复删除，通过。未验证原生UI。到期时间持久化、在线调度、装备失效处理仍待实现，不能把2162接通等同于完整到期功能。
