# 功夫小子本地 / 线上登录器（共用源码）

C# / .NET 8 WinForms 登录器，内嵌 Go 网络桥接器和 C# 客户端更新界面。
本地调试登录器与线上登录器均由此项目构建，根据连接配置显示对应环境及功能。
支持多窗口客户端目录和端口隔离，读取运行目录下的 `bridge.json`。

完整构建步骤见仓库根目录 [README](../../README.md)。
运行仍需要自行提供游戏文件、连接配置及受信任证书。

## 玩家直接使用

完整解压提供者准备的游戏文件夹，双击其中的登录器，输入账号密码后点击“启动选中窗口”。不要在压缩包内运行，也不要把 EXE 单独移动到桌面；需要桌面入口时创建快捷方式。

登录器已内嵌网络组件与客户端更新逻辑，点击启动游戏时先检查更新，保留负责定制外观的登录界面 DLL，更新功能不放在 DLL 中，无需玩家手动复制 DLL、安装 .NET 或运行命令。窗口中的“使用说明”可查看当前游戏目录；目录错误、缺少游戏文件或连接证书时会说明具体问题。

提供者应提前准备整个文件夹：登录器 EXE、游戏 `gfld.dat` 和完整资源（含 `Data`）、`bridge.json`、配置引用的连接证书。发给玩家的配置使用 `client_directory: "."`、`shared_client: true`，证书路径使用文件夹内相对路径；不能带开发者电脑的绝对路径或管理密钥。游戏资源不提交仓库。登录器 EXE 本身不包含完整游戏资源。

两个入口共存时，线上入口读取 `bridge.json`；文件名含“本地”或“线下”的入口优先读取同目录 `bridge.local.json`，不存在时兼容原来的 `bridge.json`。两份配置共用同一游戏目录，但分别指定连接证书。切换环境前关闭游戏。界面仅显示环境名称，不显示连接域名。本地入口仍需要另行运行本地服务器，不是单机离线模式。

## 本地服务器启停

连接本地调试服时，状态区域提供「启动本地服务器」「停止本地服务器」。同目录存在 `功夫小子本地服务器.exe` 时，优先打开 .NET C# 日志窗口并由它启动 `kungfu-server.exe`；未安装窗口时兼容原有直接启动。运行中不重复启动；停止仅匹配该完整路径的进程，不影响其他目录的服务器。停止会断开所有本地玩家，关闭登录器则保留服务器运行。线上连接不显示这些按钮。

同目录需要保留 `settings.private.json`、`config.json` 和服务器证书。服务器协议日志仍写入 `logs`。独立启停测试使用 `--server-control-test <测试目录>`，该目录必须包含专用fixture标识，测试不操作实际游戏服务器。

开发参数：`--root <主配置目录>`、`--self-test`、`--preview <PNG路径>`、`--start 1,2`。

## 按窗口保存账号密码

在登录器中选中窗口，填写账号密码后启动。每个窗口独立保存，切换窗口、启动、关闭登录器或点击“保存账号密码”时写入本地。启动后自动填写该游戏窗口的原生登录框，仍由玩家点击登录。

记录位于登录器配置根目录的 `launcher-components/window-N/credentials.bin`，通过 Windows DPAPI 当前用户加密；复制到其他 Windows 用户或电脑不能直接解密。清空账号和密码后保存可移除该窗口记录。凭据不写入桥接配置、进程命令行或日志。

线上登录器打开时先通过独立更新助手检查登录器自身版本，确认更新后自动替换并重启；点击启动游戏时再检查客户端资源。更新助手自动释放，玩家无需手工复制。
# 网络日志隐私

新版网络桥在写入 `online-client.log` 前，将连接地址和端口替换为 `[NET_ENDPOINT]`。玩家、通道、耗时和错误原因保留，便于排查；此项只隐藏日志，不修改连接地址或游戏传输协议。以前生成的历史日志不会因升级自动清除。
