# 功夫小子在线登录器

C# / .NET 8 WinForms 登录器，内嵌 Go 网络桥接器和 C++ 登录界面组件。
支持多窗口客户端目录和端口隔离，读取运行目录下的 `bridge.json`。

完整构建步骤见仓库根目录 [README](../../README.md)。
运行仍需要自行提供游戏文件、连接配置及受信任证书。

## 本地服务器启停

连接本地调试服时，状态区域提供「启动本地服务器」「停止本地服务器」。同目录存在 `功夫小子本地服务器.exe` 时，优先打开 .NET C# 日志窗口并由它启动 `kungfu-server.exe`；未安装窗口时兼容原有直接启动。运行中不重复启动；停止仅匹配该完整路径的进程，不影响其他目录的服务器。停止会断开所有本地玩家，关闭登录器则保留服务器运行。线上连接不显示这些按钮。

同目录需要保留 `settings.private.json`、`config.json` 和服务器证书。服务器协议日志仍写入 `logs`。独立启停测试使用 `--server-control-test <测试目录>`，该目录必须包含专用fixture标识，测试不操作实际游戏服务器。

开发参数：`--root <主配置目录>`、`--self-test`、`--preview <PNG路径>`、`--start 1,2`。

## 按窗口保存账号密码

在登录器中选中窗口，填写账号密码后启动。每个窗口独立保存，切换窗口、启动、关闭登录器或点击“保存账号密码”时写入本地。启动后自动填写该游戏窗口的原生登录框，仍由玩家点击登录。

记录位于登录器配置根目录的 `launcher-components/window-N/credentials.bin`，通过 Windows DPAPI 当前用户加密；复制到其他 Windows 用户或电脑不能直接解密。清空账号和密码后保存可移除该窗口记录。凭据不写入桥接配置、进程命令行或日志。
