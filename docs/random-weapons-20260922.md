# 随机武器修复（2026-09-22）

## 范围与状态

已实现服务端选择、数据库持久化、即时装备刷新、手动装备成功后取消随机。
只修改源码并构建候选版本，未替换运行中的本地或线上服务器。原生客户端画面仍需实测。

本服策略：选择类型时抽取一次，每局开战前再抽取；重新打开装备页仅恢复当前结果。
这属于本服选择策略，不声称还原了原运营服务器的抽取时机。只选当前玩家拥有、有效、分类匹配的武器；保留第二武器槽，不把其中武器挪进主槽。

## 数据库与配置

Store.Open 自动创建 random_weapon_settings：uid 外键、mode、instance。
普通穿戴成功会在同一装备事务删除该账户随机设置；失败不删除。
随机选取与装备更新共用账户行锁和事务，不能取得其他玩家的实例。

config.json 新增 random_weapon_types（物品编号到类型的映射）。已有配置可用以下命令合并，保留其余字段；客户端配置哈希不同会拒绝：

```powershell
python server/go-server/tools/gen_local_config.py E:\功夫小子\client <配置副本路径> --merge-weapon-types
```

本机候选配置：runtime-local/config.random-weapon-candidate.json（267 条，已核对配置哈希）。
候选程序：dist/local-server/kungfu-server-random-weapon-fix.exe。
替换程序时必须同时合并上述分类配置；不要用旧的无分类配置测试随机功能。
