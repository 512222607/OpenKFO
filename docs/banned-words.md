# 违禁词管理

当前初始配置 291 条（保存时简繁/大小写/符号等价的词会合并）。这是可调整的游戏社区词库，不是任何地区的官方禁词全集。

## 使用顺序

1. 构建新版服务器、kungfu-admin、GM 后部署到同一环境。服务器启动自动建立 `banned_words_config` 表。
2. 首次启动默认导入内置初始词库。也可以添加启动参数 `-banned-words config/banned-words.txt` 指定独立 UTF-8 文件；仅在数据库尚无配置时导入，重启不会覆盖 GM 已保存的配置。
3. GM 选择目标环境 → 违禁词管理 → 添加/批量粘贴，或导入 TXT（填写本机完整路径）。一行一词，也支持中英文逗号、分号。导入追加到草稿并去重，不立即写服务器。
4. 点击“保存词库”。服务器约 1 秒内加载新版本，无需重启。失败保留草稿；版本冲突可重新读取，先确认放弃草稿。
5. 支持搜索、删除和复制整个词库。删除后必须保存；保存空列表表示清空，之后重启也不会恢复默认词。

## 拦截范围与行为

- 创建角色、角色改名、创建房间名、修改房间名、公开聊天、私聊。
- 命中显示 `违禁词！`；不写入名字，不广播消息，不断开连接。
- 已有角色不自动改名，也不因此禁止登录；未实现的其他协议不会因此获得转发能力。
- Unicode NFKC 全半角规范化、小写化、OpenCC 常见繁体字逐字映射、去掉空白/标点/零宽符号后做包含匹配。
- 显式覆盖 SB、SHABI、CNM、NMSL 等缩写，及大陆、台湾、香港、澳门常见粗口。不会对所有汉字自动生成拼音；需要的新缩写可在 GM 中添加。
- 包含匹配故意严格，例如含 SB 的长英文也会命中；误拦时删除相应短词。OpenCC 此处采用字符映射，不承诺短语歧义及所有方言变体覆盖。
- 最多 50,000 条，每条原文/规范化后最多 64 字符，TXT 最大 2 MiB；匹配用前缀树，不逐条遍历词库。
- 审核配置读取失败时拒绝本次内容，提示稍后重试，不静默放行。

## 存储与管理接口

独立种子文件：`config/banned-words.txt`。内置副本：`server/go-server/internal/moderation/default_words.txt`。
表：`banned_words_config(id TINYINT PRIMARY KEY, revision BIGINT UNSIGNED, words JSON)`，固定 id=1。
GM 请求：`banned_words_get`、`banned_words_save`，后者携带 `banned_words: {revision, words: [...]}`。
沿用现有管理认证及 GM 版本验证；保存通过行锁与版本检查，避免多个 GM 静默互相覆盖。各环境使用各自数据库。
