# GM 用户管理

GM 左侧“用户管理”支持按 UID、账号、角色名搜索，查看金币/点券，封禁、解封、查看最近 100 条记录。
封禁期限支持 1 小时、1 天、7 天、30 天、永久；封禁和解封均须填写原因。

服务启动时自动创建 account_bans 与 account_ban_audit。状态和审计在同一事务提交，操作 ID 防止重复提交；账号不存在则不写入。
正确密码验证后仍会检查封禁状态，定时封禁到期自动允许登录。活动连接每秒检查一次数据库，封禁后通常 1 秒内关闭连接。
generation 在每次封禁时递增，即使迅速解封，也会清退封禁前的旧连接。解封后的新登录使用最新 generation。
数据库检查失败会记录 account_ban_check_failed 并下次重试，不因数据库短暂故障踢正常玩家。

需同时更新游戏服务器和 GM 的 kungfu-desktop-admin.exe；只换 GM 界面不会让旧服务器支持封禁。
旧启动器可被服务器拦截，但要显示明确的“账号已被封禁”原因，需使用含 account_banned 提示的新网络桥。

此次构建位于 dist/user-management，尚未替换正在运行的服务及 GM，未发布线上。
先停止线下游戏服务，备份后替换 kungfu-server.exe，再启动完成建表；然后使用同目录的 GM管理器测试。
