# 本地服务器日志窗口（.NET C#）

WinForms 独立 EXE，读取服务器已有的 UTF-8 日志文件，不监听网络端口、不上传日志，也不改变线上日志的输出格式。Go 仍负责游戏和统一协议日志；本程序负责本地显示及本地进程启停。

在此源码目录构建（需要 .NET 8 或更高 SDK）：

```sh
dotnet publish -c Release -r win-x64 --self-contained true -o ../../dist/local-server-monitor
```

生成 `功夫小子本地服务器.exe`，已包含 .NET 运行时。将它放到本地 `kungfu-server.exe` 同目录，双击即可读取该目录 `logs/protocol-*.log`；点击「启动服务器」启动本地测试服，也可传 `--start` 自动启动。附带 `--server-dir "自己的本地服务目录"` 可选择已有本地目录，无线上模式。

本地服务的 `settings.private.json`、`config.json`、证书及配置引用的凭据应保留，不提交到 Git。已运行的本地服务可直接接入日志，不重启它。关闭窗口会停止**本窗口启动**的服务器；只是接入既有服务器时不停止它。手动「停止服务器」仅操作所选目录下的精确 EXE 路径。

- 虚拟列表展示时间、玩家、账号、方向、协议名称、字节数；可筛选和暂停。
- 选中记录后，下方「中文详情」显示已确认的语义，「原始数据 JSON / HEX」保留完整载荷。未知字段不猜测。
- 待发送与已发送分开显示，认证信息延续服务器的脱敏，不恢复密码/token。
- 界面保留最近 5000 条 / 32 MB；后台队列也有限额。隐藏、清空、暂停与繁忙时跳过显示都不改原始日志。打开已有大文件从末尾512 KB开始，完整历史请在日志目录查阅。
- 自动跟随服务器新建的日志文件；半行和跨读取块的 UTF-8 字符会等完整后显示。
- 启动前的 SSH/数据库错误由子进程输出接收，另外保存 `logs/monitor-startup.log`。不开放公网日志服务。

自动验证（创建隔离临时日志和隐藏窗口，不操作现有服务器）：

```sh
功夫小子本地服务器.exe --self-test --result monitor-self-test.json
```

覆盖追加/重启切换/半行/UTF-8、原始数据保留、筛选、原生虚拟列表及详情Tab。生成JSON结果和窗口渲染图。
