# 本地后台更新包（Windows x64）

这是已有本地测试服的程序更新包，不是首次安装包。

1. 在本地登录器或后台中停止本地服务器，然后关闭旧后台窗口。当前游戏连接会断开。
2. 将包中的 `功夫小子本地服务器.exe` 和 `kungfu-server.exe` 复制到原来的本地服务目录，覆盖同名文件。
3. 保留原目录中的 `settings.private.json`、`config.json`、证书、配置引用文件及 `logs`，不要删除或覆盖它们。
4. 双击 `功夫小子本地服务器.exe`，点击「启动服务器」。窗口显示中文协议日志，选中一行可查看详情及「原始数据 JSON / HEX」。

界面 EXE 包含 .NET 运行时。Go 工作进程由界面管理，无需 CMD 或 PowerShell 启动。更新包不含数据库密码、隧道令牌、游戏客户端或玩家数据；仍使用你原来的独立测试库。

`manifest.json` 记录构建时的 Git 提交和两个 EXE 的 SHA256，方便核对版本。它只说明包内文件版本，不代表运行中的服务器已完成替换。
